## 확인 범위와 유지보수

- 8개 공식 홈페이지는 실제 브라우저 접근 시 HTTP 200을 확인했다. 하츠는 공식 한국어 메인으로 이동한다.
- 전화는 공식 공개 번호를 `tel:`로 연결한다. QA 중 실제 발신·상담·예약은 하지 않았다.
- 새 데이터에는 가격, 평점, 리뷰 수, 영업시간, 응답시간, 품질 인증 배지를 넣지 않았다.
- `repairShops.ts`의 업체는 합성 `prototype` 데이터라 이 목록에 사용하지 않았다. `LeafletRepairMap`에 필요한 실제 좌표가 없어 기존 외부 지도 검색 방식을 사용했다.
- 사용자 프로필 위치와 업체별 실제 출장 범위를 신뢰성 있게 대조할 자료가 부족해 거리순 정렬이나 지역 필터를 적용하지 않았다. 공시된 서비스 지역만 표시한다.
- 방역·실리콘 재시공 등 이번 조사 범위 밖의 서비스는 안내 문구와 기존 서비스명 지도 검색을 유지한다. 임대인·관리실 연락처를 임의로 생성하지 않는다.
- 외부 서비스 정보는 바뀔 수 있다. 갱신할 때 `checkedAt`과 필드별 `sources`를 함께 업데이트한다.

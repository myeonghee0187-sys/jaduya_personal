## 발표의 중심

같은 자취라도 필요한 정보는 다르다. 자두야는 사용자의 상황을 기준으로 흩어진 정보를 연결한다.

슬라이드는 문제 발견과 설계 근거를 설명하고, 실제 결과물은 프로토타입에서 보여준다. 페르소나 세 장을 연속 소개한 뒤 프로토타입으로 한 번 전환한다. 시연에서는 같은 기능을 반복하지 않는다.

## 편집 판단

- 일정표는 본편에서 제외한다.
- 설문 수치와 인사이트는 분리하되, 경쟁사 분석은 인사이트 장에 압축한다.
- HMW와 가치 제안을 한 장으로 통합한다.
- 원본 IA의 독립 혜택 메뉴는 현행 프로젝트 IA에 맞춰 관련 맥락의 정보로 정리한다. 메인 탐색은 생활 / 돈 관리 / 홈 / 커뮤니티 / 마이이다.
- MVP는 모든 화면의 목록 대신 사용자가 얻는 역할별로 구조화한다.
- 페르소나는 반드시 독립 프레임 세 장으로 제작한다. 원본의 동일 온보딩 목업 대신 실제 확인한 서로 다른 대표 화면을 사용한다.
- 결과 장은 사용자 조사로 검증된 성과나 개선율을 주장하지 않는다. 시연에서 보여준 경험 차이만 정리한다.
